# FivePrayer Version 2.4.0 - Release Notes

## 📢 What's New in Version 2.4.0

### ✨ New Features

**🕌 Custom Calculation Methods**
- Users can now add their own custom calculation methods for prayer times
- Greater flexibility to match local mosque or community preferences

**🖨️ Enhanced Printing Features in Display Settings**
- **Hide Printer Timetable Button**: When enabled, the printer timetable button will be hidden from the calendar display
- **Hide Month Selection**: When enabled, the month selection dropdown will be hidden from the calendar display
- **Printer Button Options**: Configure the printer timetable button behavior
- **Printer Timetable Button URL**: Enter a custom URL to redirect when the printer timetable button is clicked. Leave empty to use default print functionality
- **Show Custom URL Button**: Turn on to show your custom URL button on the calendar (this replaces the print button). Turn off to show the print button instead
- **Auto-Print Page URL**: Enter the URL of the dedicated print page where the print dialog should automatically trigger. Make sure this page has the timetable calendar shortcode ([Fp_TimeTable_Monthly] or block). Leave empty to disable
