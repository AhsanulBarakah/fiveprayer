- API-Documentation.md - API documentation for the plugin
- cache_compatibility_analysis.md - Analysis of cache compatibility issues
- CACHE_FIXES_DOCUMENTATION.md - Documentation for cache fixes
- core-files-documentation.md - Documentation for core files
- CSS_FIXES_DOCUMENTATION.md - Documentation for CSS fixes
- CustomPrayerTimeSchedules_Documentation.md - Documentation for custom prayer time schedules
- DEVELOPMENT.md - Development guidelines and setup
- GitGuide.md - Git workflow and guidelines
- INDEX.md - Main index file for documentation
- Readme_Structure_core.md - Structure documentation for the core readme
- TV_DISPLAY_MODE.md - Step-by-step user guide for the TV Display Mode feature, including the layout width that decides which page-builder breakpoint the TV gets and the on-screen screen report, plus the mosque deployment workflow (each masjid keeps its own site and location while sharing calculation settings and translations through the administrator-only export/import)
- LOCAL_NETWORK_TESTING.md - Guide to sharing a locally-hosted site with the TV, phone or tablet on the same network (Share on Local Network) without database changes, including an Issues & Fixes troubleshooting section (Windows firewall network profiles, guest networks, client isolation, public-IP limits, false-negative command-line checks)
- utility-files-documentation.md - Documentation for utility files

## Organization Summary

The documentation is organized into several categories:
1. **Core Plugin Documentation** - General plugin information and setup
2. **Breakdance Integration** - Comprehensive documentation for Breakdance integration features
3. **Common Components** - Shared components documentation
4. **Dynamic Tags** - Documentation for dynamic tag functionality
5. **Elementor Integration** - Documentation for Elementor integration features

Each category contains specific guides for installation, development, usage, and troubleshooting.
